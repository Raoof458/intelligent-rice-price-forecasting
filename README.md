# Intelligent Rice Price Forecasting

A Deep Learning based Rice Price Forecasting System using LSTM Networks for 2026 Market Analysis.

---

## 📌 Project Overview

This project predicts future rice prices using Artificial Intelligence and Deep Learning techniques.  
The model uses historical rice market data and applies LSTM (Long Short-Term Memory) neural networks to forecast future trends accurately.

The system helps:
- Farmers
- Traders
- Researchers
- Agriculture Analysts

make better market decisions.

---

## 🚀 Features

- Real-time rice price forecasting
- Deep Learning based prediction
- Time-series analysis using LSTM
- Interactive data visualization
- High prediction accuracy
- Future trend forecasting

## 📂 Dataset Information

Dataset Source:
- Yahoo Finance (ZR=F)

Data Includes:
- Historical rice prices
- Market trends
- Time-series records

Data preprocessing techniques:
- Missing value handling
- Normalization using MinMaxScaler
- Sequence generation using 60-day windows

---

## ⚙️ Model Architecture

The forecasting model uses:

1. Input Layer
2. Stacked LSTM Layers
3. Dropout Layers
4. Dense Output Layer

The model learns historical price patterns and predicts future rice prices.

## 🔄 Working Methodology

### Step 1: Data Collection
Rice price data collected from Yahoo Finance.

### Step 2: Data Preprocessing
- Data cleaning

### Step 4: Prediction
Future rice prices predicted using trained model.
